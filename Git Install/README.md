How to Download and Install Git for Windows / Ako stiahnuť a nainštalovať Git pre Windows
======================================================================================

This guide shows the process of searching for Git on Google, navigating to the official download page, and selecting the Windows installer.  
Tento návod ukazuje postup pri hľadaní Gitu cez Google, prechode na oficiálnu stránku sťahovania a výbere inštalátora pre Windows.

* * *

Visit the Git installation page via the link / Navštívte stránku inštalácie Gitu cez odkaz
----------------------------------------------------------------------------------------
[Git - Install for Windows](https://git-scm.com/install/windows)  
[Git - Inštalácia pre Windows](https://git-scm.com/install/windows)

* * *

![](https://3wnk7clnt5z9buow.public.blob.vercel-storage.com/8775a794-d0f3-406e-a4c9-e0d24156a062/190215e8-e48b-4957-b9f2-cdc12bf1c477-thumb.png)

Choose the Windows Installer / Vyberte inštalátor pre Windows
------------------------------------------------------------
On the installation page, click the link for 'Git for Windows/x64 Setup' to start downloading the installer file.  
Na stránke inštalácie kliknite na odkaz 'Git for Windows/x64 Setup' pre spustenie sťahovania inštalačného súboru.

* * *

![](https://3wnk7clnt5z9buow.public.blob.vercel-storage.com/8775a794-d0f3-406e-a4c9-e0d24156a062/91bf1b28-2a1b-4cf5-922d-be77b98b8a35-thumb.png)

Find the downloaded Git installer and run it / Nájdite stiahnutý inštalátor Gitu a spustite ho
---------------------------------------------------------------------------------------------
Follow the installer prompts to complete the installation. Default options are suitable for most users.  
Postupujte podľa pokynov inštalátora pre dokončenie inštalácie. Predvolené nastavenia sú vhodné pre väčšinu používateľov.
