How to Download and Install Git for Windows
===========================================

This guide shows the process of searching for Git on Google, navigating to the official download page, and selecting the Windows installer.

* * *

Navštív stránku inštalácie gitu cez odkaz
-----------------------------------------

[Git - Install for Windows](https://git-scm.com/install/windows)

* * *

Choose the Windows Installer
----------------------------

On the installation page, the user clicks the link for 'Git for Windows/x64 Setup' to start the download of the installer file.
